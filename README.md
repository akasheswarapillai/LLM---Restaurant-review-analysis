# **Restaurant Review Analysis Using LLM**

This project uses **Mistral-7B-Instruct and Prompt Engineering** to analyze customer reviews and understand restaurant performance.

### **Key Features**

➤ **Overall Sentiment Analysis:** Classifies customer reviews into Positive, Negative, and Neutral sentiments.

➤ **Aspect-Based Sentiment Analysis:** Evaluates individual aspects such as food quality, service, and ambience.

➤ **Feedback Extraction:** Identifies specific features that customers liked or disliked.

➤ **Personalized Response Generation:** Generates polite and personalized responses based on customer feedback.

➤ **Structured Output:** Returns the analysis results in JSON format for easy interpretation.

### **Technologies Used**

**Python | Pandas | Mistral-7B-Instruct | Hugging Face Transformers | Prompt Engineering | Google Colab**

### **Objective**

To convert customer reviews into meaningful insights, identify areas that need improvement, understand customer satisfaction, and help restaurants improve their service quality through LLM-based analysis.

### **Key Findings**

➤ **Service** received the most negative feedback.

➤ **Ambience** received the most positive feedback.

➤ The analysis helps restaurants identify their strengths and areas that require improvement based on customer opinions.
